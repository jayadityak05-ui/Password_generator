# Password_calculator
This project is a simple Python password generator that creates passwords using lower, upper alphabets and digits and special characters.

# Project Structure
Basic-Password-Generator/
│
├── input.py
├── function.py

# Function.py
This file defines 2 functions generate_special() and generate_no_special() which generate the passwords with and without special characters respectively. 

# Input.py
This file handles user input. Also it provides the choice of using special characters to the user and generate a password with/without special characters.
